1. 如何做出随着模型能力提升而提升的 harness 产品？
  - 哪些是 harness 该管的，哪些是模型该管的。边界是什么
  - harness 应该与 **业务** 有关吗？**【详情见示例】**
    - 我们在教一个孩子的时候，会分别专门教他**分析销售数据**和**分析用户行为数据**两套逻辑吗？不会吧，如果需要分别教 llm，则说明 llm 还不够聪明，这应该是大脑负责的事情，不应该 harness 来做。
