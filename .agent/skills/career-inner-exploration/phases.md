# 职业初探 — 分主题问题库

供 `career-inner-exploration` skill 使用。**每次只从当前主题选一个问题发出**；用户回答后再选下一个，不要整表抛出。

---

## 主题 1：内心真实需求 → `exploration.inner_needs`

探索：用户 **真正想解决** 的状态或问题（未必等于表面想跳槽）。

| 深度 | 示例问题（择一） |
|------|------------------|
| 入口 | 过去一年里，哪 **三个时刻** 让你最想「改变现状」？分别触发点是什么？ |
| 具体化 | 如果问题解决了，你希望 **日常的一天** 有什么不同？请描述一个典型工作日。 |
| 对照 | 你现在的工作，哪一部分是在 **满足别人期待**，哪一部分是真正 **你自己要的**？ |
| 底线 | 有没有一件事，如果未来两年仍然没有改善，你会觉得 **无法接受**？ |

---

## 主题 2：渴望 → `exploration.desires`

探索：理想工作/生活方式、成就感来源（可含情感与非金钱动机）。

| 深度 | 示例问题（择一） |
|------|------------------|
| 入口 | 你羡慕或过过的 **某一种职业状态** 是什么？具体羡慕其中的哪一点？ |
| 成就感 | 最近一次感到「这事我做成了」是什么时候？成的是 **什么事**？ |
| 生活方式 | 工作之外，你希望保留多少时间给 **家庭/健康/学习/创作**？各占多少比较理想？ |
| 反面 | 有哪些「别人觉得好」的机会，你 **明确不想要**？为什么？ |

---

## 主题 3：职业需要 → `exploration.career_needs`

探索：理性层面的岗位、行业、成长、稳定性诉求。

| 深度 | 示例问题（择一） |
|------|------------------|
| 入口 | 下一份工作，**必须满足** 的 2–3 个条件是什么？（如技术栈、职级、城市、远程） |
| 成长 | 你更希望接下来 2 年 **深度专精** 还是 **拓宽面**？为什么？ |
| 行业 | 有没有 **坚决不考虑** 的行业或公司类型？原因是什么？ |
| 权衡 | 如果只能在「薪资」「成长」「稳定/WLB」里排序，你的顺序是？ |

---

## 主题 4：当下最重要 → `exploration.priorities_now`

探索：未来 6–12 个月最优先的 1–3 件事（可含非职业但影响职业的选择）。

| 深度 | 示例问题（择一） |
|------|------------------|
| 入口 | 未来 **半年**，若只能做好一件事，你会选什么？ |
| 排序 | 下面这些里，请排出前二：**换工作 / 晋升 / 转行 / 提升技能 / 改善收入 / 平衡生活**（可补充）。 |
| 约束 | 有没有 **时间、家庭、健康、地域** 上的硬约束，会直接影响职业选择？ |
| 时机 | 为什么 **是现在** 考虑变动，而不是一年前或一年后再说？ |

---

## 主题 5：当前问题 → `exploration.current_problems`

探索：阻碍、焦虑、技能/机会缺口。

| 深度 | 示例问题（择一） |
|------|------------------|
| 入口 | 当前最消耗你精力的是 **人、事、技术、还是不确定性**？各举一例。 |
| 技能 | 针对你心仪的方向，你自觉 **差一口气** 的能力是什么？有具体例子吗？ |
| 机会 | 是 **没有机会展示**，还是 **不知道去哪找** 机会？ |
| 情绪 | 焦虑主要来自 **对比他人**、**年龄/空窗**，还是 **对能力下降的担心**？ |

---

## 交织对照（五主题进行中，每 1–2 主题后择一问）

与内心主题 **对照**，把用户刚说的价值取向落到简历证据上；**每次只问一个**。

| 时机 | 示例问题（择一） |
|------|------------------|
| 主题 1–2 后 | 你刚说的「最想改变的一点」，在简历 **哪一段经历** 里最能体现？有没有相反的反例经历？ |
| 主题 3–4 后 | 下一份工作的 **必须条件** 里，有没有哪条在你简历里 **几乎没出现**？可能是没写还是真没做过？ |
| 任意 | 简历里 **最长的一段** 描述，如果删掉一半，你会先删哪句？为什么那句其实不重要？（暴露可追问点） |

---

## 简历深度追问（集中段，五主题之后）→ `resume.experience_bank`

**前提**：已读 `resume.source_path` 指向的基线 Markdown。简历是个人经历的 **浓缩**，本段目标是 **尽量多** 收集经用户确认的可落档素材，**不** 润色该 Markdown 文件。

**节奏**：至少 **3–5 轮**，一次一问；每轮只追一个缺口（时间段 / 项目 / 贡献 / 数字 / 技能）。

| 深度 | 示例问题（择一） |
|------|------------------|
| 缺口扫描 | 按时间线看，有没有 **空窗或很短的条目** 其实背后有大项目？ |
| 贡献边界 | 「负责 XX 系统」里，**设计 / 实现 / 上线 / 运维** 你各占哪几块？有没有唯一负责人？ |
| 量化 | 这件事如果只能留 **一个数字**（用户量、延迟、成本、人天、营收），你会选哪个？ |
| 未写入能力 | 这段经历里用过的 **技术/工具**，有没有简历里没写的？为什么当时没写？ |
| 可迁移 | 若目标 JD 强调 **{用户 career_needs 中的关键词}**，你还有哪些经历 **能证明** 但简历没提？ |
| 验证 | 我整理成一条：「{镜像一句}」—— **准确吗？** 要改哪几个字？ |

落档：用户确认后写入 `experience_bank.items[]`（字段见 [B02 §5.2.2.1](../../docs/prd/B02.%20流程-职业初探%20PRD.md#5221-简历深度追问要求)）；段末汇总为 `narrative_summary` 并请用户确认。

**无简历时**：说明追问价值并邀请粘贴；用户拒绝则 `items: []`，`narrative_summary` 记「待用户补充简历后补采」，**不阻塞** 五主题落档。

---

## 交叉深挖（全主题 + 简历集中段之后）

| 场景 | 示例问题 |
|------|----------|
| 矛盾 | 你既希望稳定又渴望创业氛围——若只能保一个，半年后你更后悔丢哪个？ |
| 模糊 | 你提到「想做更有价值的事」——对你个人而言，**价值** 的判据是什么？ |
| 具象 | 你最怕的失败画面是什么？成功画面又是什么？ |

---

## 路径草案呈现（可选，2–3 条）

用表格或短段落，**不做技术实现方案**：

| 路径 | 适合若… | 6–18 个月可能动作 | 3–5 年可能影响 |
|------|---------|-------------------|----------------|
| A | … | … | … |
| B | … | … | … |

用户选定或混合后，再写入 `career.selected_path_id` 等字段（须用户确认）。
