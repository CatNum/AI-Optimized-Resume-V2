## 0. 摘要

当前职业初探存在两个产品层问题：

1. 旧 B02 PRD 将身份线定义为「五主题」，但这些主题主要来自项目内经验总结，未被验证为足够完整的职业咨询框架。
2. 现有实现主要依赖 worker 返回 `phase_status=segment_complete` 与 `explore_closure` 齐套来收束，轮次/深度判定代码未完整接入主流程，容易出现「能力线尚未深挖，初探却被判完成」。

本 spec 将职业初探身份线升级为 **六维画像**，并采用 **半结构化深聊**：

- 前半段偏心理理解：先理解用户为什么来、如何理解自己、真正重视什么、什么让其有能量或被消耗。
- 后半段偏职业决策：再把心理理解翻译为现实约束、行动准备、岗位/公司筛选与后续能力补齐。

本期只定义业务设计、状态标准与验收口径，不直接规定具体代码实现。

---

## 1. 背景与原则

### 1.1 不再把「五主题」当作固定问卷

原 B02 身份线五主题为：

- 内心真实需求
- 渴望
- 职业需要
- 当下最重要
- 当前问题

这些主题仍有价值，但它们更像内部信息槽，而不是用户可感知的咨询步骤。若按主题逐项提问，体验会接近问卷；若完全自由追问，又容易缺少结构并提前完成。

### 1.2 参考的职业咨询视角

本设计吸收以下职业咨询常见关注点，但不直接复刻任何单一理论：

- NCDA 职业咨询能力中的能力、兴趣、价值观、人格、自我概念、生活角色、职业身份与决策过程。
- Career Construction / Life Design 对职业身份、自我叙事、生命主题与适应力的关注。
- Career Anchors 对才能、动机/需要、价值观及不可妥协项的关注。

### 1.3 产品原则

- **先理解，再决策**：用户先感到被理解，再进入岗位/公司/能力/行动策略。
- **像咨询，不像审问**：不按 1 到 6 机械提问，而是从用户当前最强烈的问题切入。
- **有结构地自由**：允许自然深聊，但后台必须追踪六维画像覆盖度。
- **证据优先**：画像判断应尽量有用户原话、经历证据或明确推断依据。
- **不为单一用户定制**：业务标准面向通用 IT 从业者，不使用 demo session 中的个人内容作为通用规则。

## 2. 新目标

### 2.1 初探身份线的目标

身份线不再只回答「用户想要什么」，而是形成一份可被用户修正、可被后续流程消费的 **职业自我理解画像**。

身份线输出应支持：

- 市场分析：判断哪些机会符合用户真实动机与约束。
- JD 分析：判断岗位亮点/风险是否触碰用户职业锚。
- 简历策略：决定叙事主线、转型逻辑与价值锚点。
- 能力补齐：识别短期必须补齐与可入职后补齐的能力。

### 2.2 初探整体的目标

完整初探由两条线组成：

| 线 | 目标 | 输出 |
|----|------|------|
| 身份线 | 理解用户是谁、为什么选择、不能妥协什么、如何走过去 | 六维画像 |
| 能力线 | 理解用户有什么、能证明什么、缺什么证据、哪些能力可迁移 | 能力图谱与经历素材 |

本 spec 重点定义身份线六维画像，并约束它与能力线的衔接。

## 3. 身份线六维画像

### 3.1 六个底层信息槽

| 维度 | 核心问题 | 主要用途 |
|------|----------|----------|
| 当前职业问题 | 用户为什么现在来聊，最想解决什么卡点 | 确定咨询入口与紧迫性 |
| 职业身份与自我叙事 | 用户如何理解自己，希望成为怎样的职业人 | 支撑定位、转型叙事与面试表达 |
| 价值观与职业锚 | 用户最不愿妥协什么 | 支撑岗位/公司筛选 |
| 兴趣与能量来源 | 什么让用户持续投入，什么会消耗用户 | 支撑长期匹配与反模式识别 |
| 现实约束与生活角色 | 理想方案在现实中能否落地 | 支撑可执行策略 |
| 适应力与行动准备 | 用户如何面对变化，准备怎么走过去 | 支撑短期行动计划与风险预案 |

### 3.2 维度状态

每个维度都有独立状态：

| 状态 | 含义 |
|------|------|
| `missing` | 未出现相关信息 |
| `thin` | 只有标签或泛泛表达，不能支撑判断 |
| `usable` | 有具体原因、偏好、约束或经历证据，可支撑后续判断 |
| `sufficient` | 有结论、动机、取舍、反例或排序，可支撑高质量职业决策 |

### 3.3 证据要求

每个维度应保存证据：

| 字段 | 含义 |
|------|------|
| `summary` | 当前维度归纳 |
| `evidence` | 用户原话或事实依据 |
| `inference` | Agent 推断，必须标明不是用户原话 |
| `open_questions` | 仍需补问的问题 |
| `status` | `missing` / `thin` / `usable` / `sufficient` |

## 4. 六维足够标准

### 4.1 当前职业问题

足够标准：

- 明确当前主要职业问题是什么：转型、迷茫、求职、薪资、能力焦虑、晋升受阻、工作倦怠、方向不清等。
- 明确为什么是现在要解决：离职、项目结束、年龄阶段、薪资停滞、行业变化、组织变化、长期不满累积等。
- 明确问题里的核心张力或风险：短期收入 vs 长期成长、稳定 vs 转型、兴趣 vs 市场、能力不足 vs 时间压力等。
- 能用一句话概括用户当前最主要的职业卡点。

### 4.2 职业身份与自我叙事

足够标准：

- 明确用户当前如何定义自己：当前角色、经验背景、核心能力标签。
- 明确用户希望转向或强化的目标身份。
- 明确当前身份到目标身份之间的迁移逻辑：哪些经验、能力、项目或特质能支撑变化。
- 明确用户想保留的旧身份标签，以及不想继续被限制的旧标签。
- 能形成一段可用于后续简历、面试、职业定位的自我叙事。

### 4.3 价值观与职业锚

足够标准：

- 明确用户最看重的 1-3 个职业锚：成长、公平回报、稳定性、自由度、影响力、技术深度、管理路径、生活平衡等。
- 明确每个职业锚为什么重要，而不是只停留在标签。
- 明确哪些可以短期妥协，哪些不能长期妥协。
- 明确哪些情况会触发明显不适、失望或离开意愿。
- 明确多个职业锚冲突时的排序。

### 4.4 兴趣与能量来源

足够标准：

- 明确用户对哪些工作内容、问题类型或场景有持续兴趣。
- 区分「市场热门」与「真实有能量」：用户是真的喜欢，还是只是觉得应该去做。
- 明确至少 1 个正向能量来源：什么任务会让用户投入、兴奋、有成就感。
- 明确至少 1 个负向消耗来源：什么状态会让用户疲惫、厌烦、失去动力。
- 明确兴趣是否有证据支撑：过去经历、长期学习、项目投入、主动输出、反复选择等。
- 能判断用户适合靠近哪些工作内容，应该避免哪些长期工作状态。

### 4.5 现实约束与生活角色

足够标准：

- 明确时间约束：多快需要做出选择、入职、转型或产生收入。
- 明确经济约束：薪资底线、收入压力、可承受空窗期、短期降薪空间。
- 明确空间约束：城市、远程、通勤、搬迁意愿。
- 明确生活角色约束：家庭责任、健康状态、年龄阶段、照顾责任、个人生活优先级。
- 明确风险承受能力：能接受多大不确定性，多长时间看不到结果会不安。
- 能据此判断哪些职业建议虽然理想但不现实。

### 4.6 适应力与行动准备

足够标准：

- 明确用户面对变化的方式：主动学习、试错、等待机会、逃避压力、依赖外部推动等。
- 明确当前已有行动：学习、投递、项目、作品集、面试准备、人脉、复盘等。
- 明确短期优先级：接下来 1-4 周最重要的行动是什么。
- 明确能力缺口和补齐策略：哪些必须先补，哪些可以边工作边补。
- 明确备选方案：如果首选路径受阻，用户是否有可接受的 Plan B。
- 明确用户需要什么支持：信息、结构化计划、情绪稳定、外部反馈、简历包装、面试训练等。

## 5. 对话阶段设计

### 5.1 阶段一：自由探索

目标：从用户当前最强烈的问题切入，不让用户感觉在填表。

优先覆盖：

- 当前职业问题
- 职业身份与自我叙事
- 价值观与职业锚
- 兴趣与能量来源

规则：

- 一次只问一个问题。
- 优先追问用户刚刚表达出的张力、反复词、情绪词、取舍词。
- 不在用户刚进入时罗列六个维度。
- 如果用户只给标签，应追问原因、背景、代价或反例。

### 5.2 阶段二：结构补全

触发：自由探索已有主线，但六维画像仍存在 `missing` 或 `thin` 维度。

规则：

- Agent 可以显式说明「我还想补两个维度」。
- 优先补现实约束与行动准备，因为它们决定建议能否落地。
- 补问仍保持咨询语气，不改成表单语气。

示例话术：

```text
我现在大致理解你的方向了，但还缺一个现实约束：你现在最不能接受的时间/收入风险是什么？
```

```text
我还想补一下行动准备：如果首选路径短期受阻，你能接受的备选策略是什么？
```

### 5.3 阶段三：画像确认

触发：六维画像达到 `usable` 完成门槛。

规则：

- Agent 输出「身份线画像小结」。
- 不直接宣布完成。
- 必须邀请用户修正。

画像确认问题：

```text
我现在对你的职业画像理解是下面这版。请你重点看三件事：哪一句不准？哪个判断太武断？还有哪个点没说透？
```

### 5.4 阶段四：转入决策画像

用户确认身份线后，Agent 再进入职业决策画像：

- 目标方向
- 机会筛选标准
- 能力差距
- 行动优先级

这一步可以与能力线结果合并，不应在身份线尚未确认时提前做强判断。

## 6. 完成判定规则

### 6.1 可用完成

允许进入市场/JD/简历阶段，但画像可能还不是很深。

要求：

- 六个维度都有内容。
- 当前职业问题、职业身份、现实约束、行动准备必须达到 `usable`。
- 价值观与兴趣至少不能是 `missing`，允许后续继续补。
- 至少完成一次画像小结。
- 用户没有明显反驳或补充未处理。

### 6.2 充分完成

适合高质量职业咨询和长期档案沉淀。

要求：

- 六个维度全部达到 `sufficient`。
- 至少识别出 1 个核心职业张力。
- 至少识别出 1-3 个职业锚，并有排序。
- 至少识别出正向能量来源和负向消耗来源。
- 至少有一次用户修正或确认画像的过程。
- 最终画像可以直接支持岗位筛选、公司筛选、能力补齐、简历叙事。

### 6.3 轮数保护下限

轮数不是唯一完成条件，但要作为防止过早完成的保护下限。

建议：

- 身份线最少 5 轮有效问答。
- 5 轮内即使六维画像看似完整，也必须做一次画像确认，不能直接完成。
- 若 5 轮后六维画像不完整，继续补问。
- 若进入充分完成模式，通常需要 8-12 轮。

### 6.4 用户反驳后的规则

如果用户对画像小结提出反驳、纠正或补充：

- 对应维度退回 `thin` 或 `usable`。
- 本轮不能完成身份线。
- Agent 必须先处理修正，再重新输出确认小结。

## 7. 与能力线的关系

### 7.1 能力线不应被身份线小结替代

能力线的目标是沉淀：

- 项目经历
- 职责边界
- 个人贡献
- 量化成果
- 技术栈证据
- 可迁移能力
- 缺失证据

身份线可以识别「用户重视技术深度」或「希望转型」，但不能代替能力线追问「哪些经历能证明」。

### 7.2 推荐节奏

采用半结构化交织：

1. 身份线自由探索 2-3 轮。
2. 能力线插入 1 轮，追问与身份线价值锚相关的经历证据。
3. 身份线继续补全缺口。
4. 能力线集中深挖 3-5 轮。
5. 最终合并为「自我理解 + 能力证据」初探总结。

### 7.3 能力线最低要求

能力线应至少达到：

- 识别 2-3 个可用于后续简历/JD 的经历素材。
- 至少 1 个经历包含职责边界、个人贡献、结果或证据。
- 明确 1-3 个能力缺口或证据缺口。
- 明确哪些素材与用户身份线中的职业锚/目标身份相关。

## 9. 错误处理与防护

### 9.1 防止过早完成

禁止仅因以下条件完成身份线：

- worker 返回 `phase_status=segment_complete`
- 已问过若干轮但没有画像确认
- 用户表达了目标岗位但没有现实约束
- 用户表达了价值观但没有取舍排序
- Agent 生成了小结但用户未确认或仍在反驳

### 9.2 防止问卷化

禁止开场直接列出六个维度并逐项要求用户填写。

允许在结构补全段说明：

```text
我还缺两个信息：现实约束和备选策略。补完这两个，我就能给你一版更稳的画像。
```

### 9.3 防止过度心理化

职业初探不是心理治疗。若用户表达明显心理危机、伤害风险或医疗/心理健康诉求，系统应转为支持性回应并建议寻求专业帮助；职业建议只作为辅助，不能替代专业心理服务。

### 9.4 防止单用户偏置

测试和示例不得依赖 demo session 中的个人信息。应使用通用 IT 从业者样例，如后端转型、测试工程师转产品、运维转 SRE、数据分析师转 AI 应用等。

## 10. 测试与验收标准

### 10.1 业务验收

- 用户可以自然表达职业问题，不需要按问卷顺序回答。
- 系统能识别六维缺口，并在合适时补问。
- 系统不会在身份线少于 5 轮有效问答时直接完成。
- 系统不会在未画像确认时完成身份线。
- 用户反驳画像后，系统不会继续推进到市场/JD。

### 10.2 自动化测试方向

应覆盖：

- 六维状态从 `missing` 到 `thin` / `usable` / `sufficient` 的判定。
- 少于 5 轮时，即使 worker 返回 `segment_complete` 也不能挂完成。
- 六维存在 `missing` 时，下一问应优先补缺口。
- 用户反驳画像小结后，完成闸门取消。
- 能力线不能被身份线小结替代。

### 10.3 回归样例

至少包含以下通用样例：

| 样例 | 目标 |
|------|------|
| 后端工程师转 AI 应用 | 测试身份迁移叙事 |
| 测试工程师转产品 | 测试自我叙事与能力迁移 |
| 运维工程师职业倦怠 | 测试兴趣/能量来源 |
| 数据分析师薪资停滞 | 测试职业锚与现实约束 |

## 12. 决策记录

### ADR-20260607-身份线采用六维画像

#### 状态

已采纳，待实现。

#### 背景

原五主题偏内在需求归纳，缺少职业咨询中对职业身份、自我叙事、生活角色、适应力和行动准备的明确覆盖。当前实现也容易依赖 worker 自判完成，导致初探过早收束。

#### 决策

将身份线升级为六维画像：

1. 当前职业问题
2. 职业身份与自我叙事
3. 价值观与职业锚
4. 兴趣与能量来源
5. 现实约束与生活角色
6. 适应力与行动准备

采用半结构化深聊：先自由探索，再结构补全，最后画像确认。

#### 影响

- 优点：
  - 更接近职业咨询师深聊体验。
  - 降低问卷感。
  - 后续市场/JD/简历判断有更稳定的心理与决策依据。
- 缺点：
  - 需要新增维度状态追踪。
  - Prompt 与完成 gate 会更复杂。
  - 测试需要覆盖更多对话状态。
