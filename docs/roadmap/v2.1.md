## 归档结论

- 2026-07-24 决定停止继续以 v2.1 名义推进，产品路线进入 [v2.2（开发中）](./v2.2.md)。
- v2.1 未满足全部验收标准，因此状态是“已归档（验收未完成）”，不是“已完成”。
- 本文保留归档时的代码、截图、测试失败和未执行验证记录，不以版本迁移覆盖或改写历史证据。
- 未完成事项只有在 v2.2 版本范围中被明确承诺时才进入 v2.2，不因归档自动转移。

## 版本范围

- 本地隔离环境中的会话、职业档案、任务状态和 HTML 产物管理。
- 一主多从的 Coordinator/Worker 执行链与 Harness 权限、Gate、Skill、Tool、Trace 控制面。
- 从职业初探、市场调研、JD 适配、优化策略确认到简历 HTML 生成和产物登记的主流程。
- Chat SSE、流程状态卡、人工确认与本地输出查看。
- L1、端到端和需真实 LLM 的分层验证入口。

## 验收标准

- 空白环境能够完成建档、初探、受控市场调研、JD 分析、策略确认、简历生成与产物登记的主链路。
- 未满足 Profile、阶段或用户确认条件时，Gate 能阻止越级执行，并给出明确的下一步。
- Worker 只能看到和调用其白名单内 Tool，重要状态变更和工具调用能够写入 Trace。
- 市场调研可显示进度，遇到登录或验证可等待用户，且支持继续、取消、重试、确认与受控复用。
- 生成的 HTML 简历可以从产物区打开，文件和产物索引保持一致。
- 确定性非 LLM 测试通过；LLM Eval 单独记录环境、模型和结果，不用 mock 结果代替真实 LLM 质量证据。

## 已知边界

- 本版本是本地优先的工程化产品，不是生产级 SaaS；尚未声明多租户、云端高可用、灾备、计费或生产 SLO。
- 市场调研依赖本机可见 Chrome、站点登录状态和页面结构；验证码、页面变化、网络异常及目标站限制都可能中断采集。
- Browser Tool 已有降级测试，但生产级降级、可恢复性和跨站稳定性仍需继续建设。
- 当前 Worker 调用仍以 `worker_id`（Worker 标识）和自然语言 `goal`（执行目标）为主，缺少按业务动作收口的强类型调用契约。
- 当前 Coordinator 的串行链不能统一证明上游业务成功后才启动下游；全局失败分类、传播、重试、降级、运行终态聚合和用户错误呈现尚未统一。
- Trace 已写入本地 JSONL，但监测、审计检索和可视化尚未产品化。
- 评测能验证确定性流程契约和部分 LLM 链路，不代表所有模型输出质量、外部站点稳定性或生产可靠性。
- 三档 HTML 已有入口与交付证据，但“保守 → 标准 → 进取”的同轮生成顺序和工作复用仍待实现。
- 产品路线版本 `v2.1` 与代码包版本 `0.1.0` 含义不同，不能互相改写。

## 非目标

- 生产级 SaaS、多租户和云端高可用。
- 未确认版本归属的长期记忆索引、Offer 对比、评测 Agent、简历模板 Skill、城市与人生选择等候选能力。
- 在 v2.1 内宣称强类型 Worker 调用或全局失败机制已经实现。
- 以历史测试数量、未执行计划或单次截图推导生产性能与可靠性。
